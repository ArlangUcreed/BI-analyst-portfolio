# Анализ рынка недвижимости Санкт-Петербурга и Ленобласти

## 📌 Описание задачи
Проанализировать рынок недвижимости Санкт-Петербурга и Ленинградской области:
- Определить сегменты с наиболее короткими и длинными сроками активности объявлений
- Выявить сезонность в публикации и снятии объявлений
- Сравнить регионы по ключевым метрикам
- Найти города Ленобласти с наиболее активным рынком

## 🛠 Используемые технологии
- **PostgreSQL** — основная СУБД для анализа
- **CTE** — для структурирования сложных запросов
- **Оконные функции** — для расчёта долей и ранжирования
- **Фильтрация выбросов** — через перцентили (99-й и 1-й)
- **FULL OUTER JOIN** — для анализа сезонности

## 📊 Ключевые результаты

| Метрика | Результат |
|---------|-----------|
| Самый активный регион | Санкт-Петербург |
| Самый быстрый сегмент продаж | "до месяца" (Санкт-Петербург) |
| Самый медленный сегмент продаж | "более полугода" (ЛенОбласть) |
| Пик публикаций | Весенние месяцы (март-май) |
| Пик снятий (продаж) | Апрель-май |
| Средняя цена за кв.м в СПб | Выше, чем в Ленобласти |
| Город Ленобласти с самым активным рынком | Всеволожск |

## 📝 Выводы
1. **В Санкт-Петербурге** объявления продаются быстрее, чем в Ленобласти
2. **Пик активности** приходится на весенние месяцы
3. **Недвижимость в СПб** дороже за кв.м, чем в области
4. **Города-спутники** (Всеволожск, Мурино) показывают высокую активность
5. **Сезонность** влияет на количество публикаций, но слабо влияет на цену

-- Анализ времени активности объявлений
WITH filtered_data AS (
    SELECT 
        a.id AS advertisement_id,
        a.days_exposition,
        a.last_price,
        f.total_area,
        c.city
    FROM real_estate.advertisement a
    JOIN real_estate.flats f ON a.id = f.id
    JOIN real_estate.city c ON f.city_id = c.city_id
    WHERE 
        a.days_exposition IS NOT NULL
        AND a.last_price IS NOT NULL
        AND f.total_area > 0
),
categorized_data AS (
    SELECT 
        CASE
            WHEN city = 'Санкт-Петербург' THEN 'Санкт-Петербург'
            ELSE 'ЛенОбл'
        END AS region,
        CASE
            WHEN days_exposition <= 30 THEN 'до месяца'
            WHEN days_exposition BETWEEN 31 AND 90 THEN 'от месяца до трёх месяцев'
            WHEN days_exposition BETWEEN 91 AND 180 THEN 'более трёх месяцев до полугода'
            ELSE 'более полугода'
        END AS activity_segment,
        last_price / total_area AS price_per_sqm
    FROM filtered_data
)
SELECT 
    region,
    activity_segment,
    COUNT(*) AS count_ads,
    AVG(price_per_sqm) AS avg_price_per_sqm
FROM categorized_data
GROUP BY region, activity_segment
ORDER BY region, activity_segment;
