# Подготовка данных маркетплейса и расчёт метрик

## 📌 Описание задачи
Очистка и подготовка данных маркетплейса: удаление дубликатов, исправление логических ошибок, добавление категориальных признаков, расчёт ключевых бизнес-метрик.

- **Описательная статистика** — PERCENTILE_CONT, CORR
- **Оконные функции** — для расчёта долей и агрегаций

-- Расчёт ключевых метрик маркетплейса
SELECT 
    COUNT(DISTINCT order_id) AS orders_count,
    COALESCE(SUM(total_amount), 0) AS gmv,
    ROUND(AVG(total_amount)::NUMERIC, 2) AS average_check,
    COUNT(DISTINCT buyer_id) AS buyers_count,
    ROUND(COUNT(DISTINCT buyer_id) * 1.0 / COUNT(DISTINCT user_id), 4) AS conversion_rate
FROM marketplace.orders o
LEFT JOIN marketplace.users u ON o.buyer_id = u.user_id
WHERE o.status != 'canceled';
